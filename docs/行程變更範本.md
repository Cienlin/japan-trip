# 行程變更範本

出發前要調整「5 個人共用」的行程時使用。Claude 會依內容修改 `data.js` 並 push，所有人打開 app 就會看到新版。

> 旅途中的臨時調整請用 app 內的編輯功能。那些修改只存在自己的手機上，不會同步給其他人。

## 使用方式

1. 把下方「本次變更」區塊填好（用不到的類型整段刪掉；同一類型有多筆就複製多份）
2. 存檔後跟 Claude 說「照行程變更範本改」
3. Claude 改完、push 之後，會把「本次變更」清空，留給下次使用

**小提醒**

- **地點名稱**：照 app 上顯示的名稱寫即可，例如「PATH 荷蘭鬆餅」「明治神宮」
- **交通**：可以留空，Claude 會依前後站補上建議路線。但地鐵路線和時間請再用 Google Maps 確認
- **前後站會自動調整**：移動地點後，前後站的「從哪裡過去」也會一起更新
- **新地點的座標**：在 Google Maps 長按該地點，畫面上方會出現座標（例如 `35.6764, 139.6993`），複製貼上即可
