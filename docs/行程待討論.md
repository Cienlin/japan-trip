# 行程待討論

目前（2026-11）5 人只在討論要去哪些地點，時間之後大家有空再一起排。這份記下排時間時要一起處理的事，處理完就刪掉。

排時間的原則：早上 8 點起床、準備好再出門；景點排早上，吃的排中午以後（見 `CLAUDE.md`）。

## 還在候補、討論過可以排的天

- 牛たん ねぎし：D2 銀座、東京車站之間
- 澀谷逛首飾店：D4 下午在澀谷的時候（同一段已排寶可夢中心、Taco Bell）
- 麥當勞、吃海鮮：還沒決定地點（行前指南「想做但還沒找地點」）

## 時間上的問題

- D5：10:00 有 3 站同時間：PATISSERIE TEN&（11:00 才開）、秋葉原、龜有，接著 10:45 是淺草寺。目前照 TEN& → 秋葉原 → 龜有 → 淺草寺的順序排，交通說明也照這個順序寫（2026-11-24）。三個地方方向不同（清澄白河在南、龜有在東北），一個早上排不下，要決定先後，或移一個到別天
- D5（12/13 週日）：American Diner Andra **週日公休**（週一～六 11:30～14:00、18:00～22:00），現在排在週日 14:00；要換到平日的午餐或晚餐，或換一家漢堡店（2026-11-12 查到）
- D5：16:30 miffy style Solamachi 到 21:00 關東煮之間沒有安排
- D1：Chiikawa 晴空塔店移到 D5 之後，19:00 check-in 到 21:45 Lawson 之間沒有安排
- D3：11:00 世界堂 → 12:00 燒肉 永福苑（午市 11:30 開）→ 12:30 Alpen，午餐扣掉走路只剩十幾分鐘
- D4：10:00 Café Kitsuné → 10:30 銀杏並木（走 15 分鐘）、16:00 HARBS → 16:30 寶可夢中心（走 12 分鐘），咖啡和蛋糕都只有十幾分鐘
- 章魚燒、大福、關東煮、居酒屋、大阪燒不指定店家，名稱已改成統稱、沒有 Google Maps 連結，到時候在附近找一間就好，排時間時可以彈性調整
- 購物的大袋子：
  - D2 Uniqlo 之後，可以寄在銀座站的寄物櫃，19:00 搭丸之內線時再拿
  - D3 Alpen 之後，晚上的居酒屋多半是小店，不方便提大袋子。可以回飯店放一趟，或把 Alpen 改到下午晚一點（開到 22:00），買完寄在新宿站西口
- D6：新退稅制度（2026/11/1 起）要在托運行李前到機場的機台辦，可能被抽到檢查。目前 12:30 從押上出發、13:30 到機場，15:30 起飛，建議提早出發
