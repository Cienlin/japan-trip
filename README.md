# 東京冬日行 🇯🇵 互動地圖與行程規劃網頁

這是為您和您 4 位朋友（共 5 人）於年底 **12/9 ~ 12/14** 的東京之旅量身打造的**互動式地圖與行程規劃網頁**。

此網頁整合了地圖視覺化、每日行程安排、景點與餐廳的交通方式和時間，並提供可點選的圖片導覽。

## 📁 專案檔案結構
- `index.html`：網頁的主體架構，載入 Leaflet 地圖套件。
- `style.css`：網頁樣式，包含響應式版面（支援手機瀏覽）、深/淺色主題切換、毛玻璃質感及動態效果。
- `data.js`：存放飯店資訊、機票時間、15+ 個美食與景點的經緯度坐標、中日文名稱、詳細介紹與交通接駁細節。
- `app.js`：網頁邏輯，控制地圖初始化、地圖標記、每日行程路線連線繪製、圖片輪播與即時出發倒數計時。
- `images/`：存放所有景點與美食的高清圖片資料夾（已自動下載完成）。

## 🚀 如何使用與開啟
此網頁為**無伺服器依賴的靜態單頁網頁 (SPA)**，您只需要：
1. **直接雙擊 `index.html`**，即可在您的電腦瀏覽器（Chrome, Edge, Safari 等）中開啟！
2. 無須安裝任何開發環境、資料庫或進行複雜的 API 設定。

## ✨ 核心功能介紹
1. **地圖標記與分類**：
   - 飯店為藍色圖標 🏨。
   - 美食為橙色圖標 🍔。
   - 購物為紫色圖標 🛍️。
   - 景點為綠色圖標 🗼。
2. **行程路線連線 (安排路線)**：
   - 在左側的「行程規劃」分頁點選 **D1 ~ D6** 的按鈕。
   - 地圖上會**自動繪製出該天的最佳行程順序連線**（虛線），幫助您快速視覺化每日的移動動線！
   - 同時，左側的時間軸會顯示每一個景點之間的**交通工具**（如半藏門線、山手線、徒步）與**估計路程時間**。
3. **點擊查看圖片與詳細資訊**：
   - 點擊地圖上的標記或左側行程卡片，網頁下方會彈出詳細資訊面板。
   - 面板左側設有**圖片輪播器**，展示該景點/食物的精美照片。
   - 提供「Google Maps 導航」按鈕，點擊即可直達 Google Maps 開始導航。
4. **行前指南**：
   - 第三個分頁整理了往返機票時間、住宿細節、東京地鐵 72 小時券建議。
   - 附帶一份互動式**行前清單**，可以勾選確認（護照、 Visit Japan Web、日幣現金、保暖衣物等）。
5. **深淺色主題切換**：
   - 點擊地圖右上角的浮動按鈕可以切換深色/淺色主題。切換時，**底層地圖的樣式也會同步切換**為精美的極簡深色/清新淺色底圖。
6. **手機版完全優化**：
   - 網頁已針對手機裝置進行自適應開發。在東京旅遊途中，您與朋友可以在手機上流暢操作，地圖、行程安排與交通資訊一目了然！
