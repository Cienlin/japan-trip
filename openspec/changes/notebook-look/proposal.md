# Proposal

## Why

使用者想讓網站更有「旅行手帳」的感覺。同時，手機上現在的畫面顏色和框線太多，看起來有點亂。2026-11-13 用 artifact 樣板（`https://claude.ai/artifact/RNG8n7mhDqtyTCEPW47Q8H`）一起討論，定案為「藍墨水手帳」外觀，使用者決定出發前就改。這是凍結期（Phase 2）的第三次破例。

## What Changes

- **字型**：全站改用霞鶩文楷（LXGW WenKai TC，Google Fonts），不再載入 Outfit 與 Noto Sans TC。字型載不到時，改用手機內建的中文字型
- **配色「藍墨水」**：
  - 淺色是偏冷的白與淺灰（不要米色），深色是深灰
  - 重點色是藍墨水，紙膠帶淺藍，螢光筆黃色
  - 每個畫面的顏色收在 3～4 種，拿掉大部分框線
- **標題列、分頁列、天數列**：
  - 都用純色背景
  - 目前所在的分頁用螢光筆標示
  - 出發倒數拿掉框
- **天數按鈕**：
  - 字不加粗，下面多一行日期，例如 D2 下面是 12/10 四，「全部」下面是 12/9–14
  - 選中的那天是一張貼了紙膠帶的小便條
- **行程**：
  - 只有行程區鋪方格紙
  - 每站是一張便條紙，時間寫在淺藍紙膠帶上
  - 拿掉時間軸的直線和類別色點，不顯示類別
  - 交通說明維持現在的樣子
- **美食景點**：
  - 每個地點是一張便條，照片像用紙膠帶貼上去的拍立得
  - 類別篩選用螢光筆標示
  - 類別改成純文字，不再有彩色底
- **預算、行前指南**：
  - 每一區是一張便條，標題寫在紙膠帶上
  - 輸入欄只有底線
  - 記帳結果像帳本，總計用雙底線
  - 進度條像螢光筆
  - 行前清單打勾後會劃掉
- **其他畫面**：地點詳細資訊、新增／編輯地點表單、確認視窗、複製變更內容都套用同一套樣式；表單的備註欄是橫線紙
- **地圖上的元件**：按鈕、版號、提示改成紙質樣式。Google 底圖、Google logo、版權文字和備用底圖都不變
- **手機狀態列**：顏色（`theme-color`）跟著新配色
- **桌機版**：側邊欄加地圖的版面也套用同一套樣式
- **不改的部分**：功能、行程資料、行前指南的文字、地圖底圖、操作方式都不變

## Capabilities

### New Capabilities

- `appearance`：App 的外觀規則，包括字型、配色、深淺色、方格紙的範圍、分頁與天數的標示方式、站的呈現方式，以及地圖上不受外觀影響的部分

### Modified Capabilities

- `itinerary`：天數按鈕要顯示該天的日期

## Impact

- **程式**：
  - `style.css`：大幅改寫顏色變數與各元件的樣式
  - `index.html`：字型網址、`theme-color`、版號
  - `app.js`：天數按鈕加上日期
  - `manifest.json`：主題色、背景色
  - `sw.js`：版號
- **資料**：`data.js` 不變。日期由 `TRIP_METADATA.startDate` 算出來，不用手動填
- **文件**：
  - `CLAUDE.md`：CSS 規則，包括字型、配色變數、方格紙只鋪在行程區
  - `README.md`：外觀說明
  - `docs/roadmap.md`：第三次破例
- **風險**：
  - 霞鶩文楷是中文字型，第一次打開要多下載一些字型檔，之後會留在快取
  - 離線又還沒下載過字型時，會改用手機內建字型
  - push 到 `main` 就會更新 5 個人的手機；樣式出問題時，用 `git revert` 退回上一版
  - 樣板只做了手機畫面，桌機版要另外檢查
