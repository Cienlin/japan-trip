# Spec Delta

## ADDED Requirements

### Requirement: 天數按鈕顯示日期

每個天數按鈕 SHALL 在天數下面顯示那一天的日期（月/日與星期幾），日期由旅程的出發日算出；「全部」按鈕 SHALL 顯示旅程的日期範圍。顯示的日期 MUST 跟手機的時區無關。

#### Scenario: 出發日是 12/9（週三）

- **WHEN** 旅程從 2026/12/9 出發
- **THEN** D1 下面是「12/9 三」，D2 下面是「12/10 四」，D6 下面是「12/14 一」

#### Scenario: 全部

- **WHEN** 旅程是 12/9 到 12/14
- **THEN** 「全部」下面是「12/9–14」

#### Scenario: 手機停在其他時區

- **WHEN** 旅伴的手機時區設在美國
- **THEN** D2 下面一樣是「12/10 四」
