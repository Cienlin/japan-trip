# Proposal

## Why

旅伴用手機看地圖時，畫面糊、字太小，地名又是日文看不懂。原因是目前用 OpenStreetMap 的 256px 圖片圖磚，在高解析度的手機螢幕上被放大顯示。離出發（2026-12-09）還有 4 週，地圖是旅途中最常用的畫面，所以使用者決定在凍結期（Phase 2）破例，出發前就換。

2026-11-12 實測：Google 圖磚不會把日本地名翻成中文（`zh-TW`、`zh-Hant` 與 `ja` 的圖磚完全相同），`en-US` 則是英文與日文並列。所以這次解決的是「糊」和「字小」；地名改善只能選英日並列，使用者知道後仍決定換 Google（清楚、字大，跟導航用的 Google 地圖 App 一樣）。

## What Changes

- 地圖底圖改用 Google Map Tiles API 的 2D 圖磚：高解析度，在手機上清楚
- 先做一個獨立的測試頁，讓使用者用手機比較地名「日文／英日並列」與字的大小「一般／兩倍字」，再決定正式版用哪一種。測試頁不影響現在的 App，正式換進 App 後刪掉
- 深色主題改用 Google 提供的深色樣式，不再用 CSS 把 Google 圖磚的顏色反轉
- 地圖上顯示 Google logo 與版權文字（Google 規定），手機版要放在底部分頁列上方，不能被蓋住
- Google 圖磚用不了時，例如服務關掉、超過每日上限、沒有網路，地圖自動改用現在的 OpenStreetMap 底圖，當作備用底圖，不顯示提示
- 標記、每天的路線、我的位置、縮放按鈕、在地圖上點選座標等功能都不變（繼續用 Leaflet）
- Google 圖磚不放進 App 自己的離線快取；離線快取只存備用底圖的圖磚
- 跟 Google 要的通行碼（session token）存在手機上重複使用到過期，看過的圖磚才能用瀏覽器快取，不必重新下載、重複計費
- 使用者在 Google Cloud 建立帳單帳戶與 API 金鑰，限定只能從 `https://cienlin.github.io/*` 使用、只能用 Map Tiles API。帳單帳戶已在 2026-11-12 從免費試用升級成付費帳戶（用多少付多少，沒有月租；剩下的試用額度用到原本的 90 天到期），並設每日上限 3,000 張，確保不超過每月 100,000 張的免費額度
- `docs/roadmap.md` 註明這次是凍結期的破例

## Capabilities

### New Capabilities

（無）

### Modified Capabilities

- `map`：新增「底圖」需求：Google 底圖（清晰、地名語言與字的大小依測試頁結果）、Google logo 與版權文字、深色樣式，以及用不了時自動改用備用底圖
- `offline-updates`：「照片與地圖圖磚」需求改成只有備用底圖的圖磚存進離線快取，Google 圖磚不存；沒網路時看到的是備用底圖

## Impact

- **程式**：`app.js`（建立地圖、主題切換、新增 Google 底圖與備用底圖的切換）、`style.css`（深色主題的 CSS 反轉只套在備用底圖、手機版 logo 與版權文字的位置）、`sw.js`（不攔截 Google 圖磚的請求）、`index.html`（版號）
- **新檔案**：獨立測試頁（暫時，換進 App 後刪掉）、Google logo 圖檔
- **外部服務**：新增 Google Maps Platform 的 Map Tiles API。需要帳單帳戶（信用卡）與 API 金鑰，金鑰會出現在網站原始碼中，靠網域限制與每日上限防止被盜用產生費用；Google 未來可能調整計費方式，每次旅行前要確認
- **使用者要做的事**：建立 Google Cloud 專案、帳單帳戶、金鑰與每日上限（2026-11-12 已完成，並驗證過網站限制會擋掉其他網站的請求）；用手機實測測試頁與正式版；旅行後可以在 Google Cloud 停用 API，下次旅行前再啟用
- **風險**：push 到 `main` 就會更新 5 個人手機上的網站。正式版出問題時會自動退回備用底圖，最差的情況就是跟現在一樣
