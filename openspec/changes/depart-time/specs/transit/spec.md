# Spec Delta

## ADDED Requirements

### Requirement: 從飯店出發的交通算到出門

共用行程裡，從飯店到當天第一站的交通分鐘數 MUST 從走出飯店算起，包含走到車站與等車的時間，不能只算搭車。這段交通說明 MUST NOT 寫死出發時刻，出發時刻以建議出門時間為準；資料檢查 SHALL 在這段交通說明寫了時刻（時:分）時提出提醒。

#### Scenario: 只算了搭車

- **WHEN** 回程那天搭京成 Access 特急 55 分鐘，從飯店走到押上站還要約 5 分鐘
- **THEN** 交通分鐘數要包含走到車站與等車的時間，不能只寫 55 分鐘

#### Scenario: 說明寫死出發時刻

- **WHEN** 當天第一段交通說明寫「09:55 押上站搭半藏門線」
- **THEN** 資料檢查提醒這段說明寫了出發時刻，改由建議出門時間顯示

#### Scenario: 不是第一段交通

- **WHEN** 當天第二站的交通說明寫「10:15 龜有站搭千代田線」
- **THEN** 資料檢查不因為這個時刻提醒
