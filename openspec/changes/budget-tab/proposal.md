# Proposal

## Why

目前的預算計算機放在行前指南，只能「估算」：用一個固定的「個人日幣預算（零用金）」換算總花費，預算目標也寫死在旅程資料裡。旅途中旅伴真正需要的是：設定自己的總預算、隨手記下實際花了多少日幣，隨時看到還剩多少預算。記帳是旅途中用的，所以使用者決定在凍結期（Phase 2）破例，出發前就做。

## What Changes

- 新增「預算」分頁，分頁順序改成：行程規劃｜美食景點｜**預算**｜行前指南
- **BREAKING**：行前指南拿掉「旅程預算與花費計算機」，全部搬到預算分頁
- 總預算由每個人在自己的手機設定，**預設空白**；沒填之前，不顯示已用百分比與剩餘預算，只提示先填總預算
- 機票（可改，預設來自旅程資料）、住宿分攤（固定台幣，已付款）、匯率（可改，預設來自旅程資料）維持現在的做法
- **BREAKING**：原本的「個人日幣預算（零用金）」改成「目前花費（日幣）」，等於逐筆花費的合計：
  - 記一筆：金額只輸入數字（手機的數字鍵盤）；備註選填；自動記錄日期
  - 不分類別；金額要大於 0；要修改就刪掉重記
  - 明細最新的在最上面；刪除前要確認
- 結果區（目前總花費＝機票＋住宿＋目前花費換算台幣、已用百分比、剩餘預算；超支時顯示超支金額）放在花費明細的上方，明細變長也不用捲到底
- 總預算、改過的機票與匯率、所有花費明細都只存在各自的手機
- 旅程資料 `TRIP_METADATA.budget` 拿掉不再使用的預算目標（`targetTwd`）與零用金（`pocketJpy`）
- `docs/roadmap.md` 註明這是凍結期的破例

## Capabilities

### New Capabilities

- `budget`：預算分頁：總預算、機票、住宿、匯率的設定，逐筆記錄花費，以及目前總花費、已用百分比與剩餘預算

### Modified Capabilities

- `pre-trip-guide`：拿掉「預算計算機」與「預算的預設值」兩項需求，移到 `budget`

## Impact

- **程式**：`index.html`（新分頁按鈕與預算分頁、行前指南拿掉計算機、版號）、`app.js`（預算分頁的畫面與互動，取代原本的 `initBudgetCalculator()`）、`style.css`（預算分頁的版面；手機底部分頁列從 3 個變 4 個）、`data.js`（`TRIP_METADATA.budget` 拿掉兩個欄位）、`tools/check-data.js`（預算欄位檢查）、`sw.js`（版號，新檔案加進 `SHELL_ASSETS`）
- **新檔案**：金額解析與預算加總的純函式，以及它們的 `node --test` 測試
- **手機上的資料**：原本存的預算欄位（改過的機票、匯率）沿用；改過的零用金不再使用，自動清掉
- **文件**：`CLAUDE.md`、`README.md`、`GLOSSARY.md`（預算相關名詞）、`docs/roadmap.md`
- **風險**：push 到 `main` 就會更新 5 個人的手機。花費明細只存在各自的手機，清除瀏覽器資料就會消失（跟其他本機修改一樣）
